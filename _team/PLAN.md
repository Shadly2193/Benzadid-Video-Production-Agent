## Added 2026-10-05: Reference Intake + Sound Harvester
- Shadly drops any downloaded/linked reel (FB/IG/Pinterest) into `_team/00_INBOX_REFERENCES/` → `/analyze-reference` runs the full Bible pass (hook, cuts, captions, camera, colour/grade numbers, SFX timeline, music BPM) and adds it as E17, E18… plus updates the Pattern Library.
- Sound Harvester: Demucs (free) separates voice / music / SFX → onset slicing → each SFX clip CLAP-tagged → the agent finds the closest **royalty-free** match (Mixkit/Pixabay/Freesound CC0) for publishing. Extracted original clips are for reference/matching only — not published (copyright).
- Colour check: per-reference measured grade (contrast, saturation, skin hue, black/white points) → reusable LUT/ffmpeg recipe.
- One home: everything (tools, models, sound library, references, agents) lives under `Video Editing/`. `_team/SETUP.md` will list every installed package + one install script, so a fresh laptop can be rebuilt.

## Portability (any device via private GitHub)
- Repo root = `Video Editing/`. Committed: agents (.md), skills, tools/*.py, Remotion/HyperFrames source, Bible reports + frame sheets, our royalty-free SFX library (small), STYLE_RULES/BRAND/PLAN, `SETUP.md` + `setup.ps1`.
- NOT committed (.gitignore, rebuilt by setup.ps1): venv, node_modules, AI models (whisper, CLAP, demucs), renders, raw client footage. Reference videos (90MB) → Git LFS or a Drive link (decide at push time).
- setup.ps1 on a new PC: checks/installs Node 22+, Python 3.12, FFmpeg (winget), creates venv + pip requirements.txt, npm ci, downloads models, sets HyperFrames telemetry off. Then `claude` in the folder → agents + skills ready.
- Rule: every new package anyone installs must be added to requirements.txt / package.json / SETUP.md in the same step.

## How to activate
Open Claude Code with the folder `Video Editing/` as working directory (agents + skills load from `.claude/`).
- `/reel-edit "Raw Videos/004. <name>"` → production team
- `/content-plan` → assistant + content team (plan / script / recording brief / status / publish)
- `/checkin` → daily check-in (also scheduled 11:00 & 15:00 BDT)
- `/analyze-reference <file>` → add a new reference reel
