# E14 — Einstein motion graphic, periwinkle duotone (716×1274, 30fps, 51.7s)
Format: **Faceless VO motion graphic, one object per sentence, constant background.** Used as the model for English v2 (rules there were measured from this file). Evidence: hook sheet, sheet_2fps_01–02.

## Hook 0–3s
- 0.0s: object already on screen (giant hand pinching a tiny Einstein, B&W duotone, drop shadow) on a **constant radial periwinkle gradient** (#E8E8FF centre → #5B5BD6 edges). Tiny italic "In," top-left.
- 0.3–0.5s: "1915" heavy condensed (Anton-like, navy #2E2E7A) **types per character**.
- 0.7–0.9s: **pixel-block dissolve** passes across the object (8px squares) = signature "digital" transition on the object only.
- 1.1s: headline shrinks/moves up; "ALBERT" then "EINSTEIN" type below the object (stacked).
- 1.8–3.0s: small decor pops around object (pocket watches, planets, orbit ellipse line drawing); tiny italic "was losing / a war" builds beside the name.
- Changes in 3s: 6, all on one stable composition.

## Rules (measured; also in project 003 notes)
- Background never changes for 51s. Only objects + text change.
- Every scene = 1 hero cut-out object centred (duotone B&W→periwinkle), 0–3 small satellite decor items, text clusters ABOVE and BELOW the object.
- Big words 4–5% of frame height, condensed caps; connectors tiny (≈1.3%) light italic; two to four tiers per cluster.
- Object entrances: pixel assemble, scale-pop with overshoot, slide; exits: all text clears on shot change.
- Highlights: white ring pulse behind object ("POUNDED"), pixel cursor arrows clicking ("ACTIVELY KILLING"), pixel-art text "E=MC²" with fire.
- Objects literal to the noun: clock "2AM", hand with chalk, violin, stopwatch, sports car "CARS", runner "LACE UP RUNNING SHOES", motorbike "ENGINE", brain on crutches "HAPPENS TO THE MIND", lightbulbs + laptop "SHORTCUT/CLIMB", brain parachute "EFFICIENCY / HUMAN TALENT".
- Music: minimal electronic ~123 BPM; digital pop SFX on each scene change (from v2 analysis).

## Engine needs (all built in P3V2): duotone filter, pixel clip-path assemble, typed headlines, cluster layout, ring pulse, cursor arrows.
